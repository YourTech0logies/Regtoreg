## Register to Registry (Зарегистрировать в реестр)

Лёгкая утилита для просмотра и последующего редактирования REG-файлов.

На данный момент программа позволяет только просматривать REG-файлы, однако в будущем планируется расширение функционала до полноценного редактора и конструктора простых REG-файлов, а также добавление «компилятора» с уровнями безопасности, ограничивающими доступ к потенциально опасным областям реестра.
